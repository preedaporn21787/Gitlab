# Gitlab

ใช้สำหรับเรียนแลป Compro ไฟฟ้า

## ระบบรดน้ำต้นไม้อัตโนมัติ

ระบบรดน้ำต้นไม้อัตโนมัติด้วยบอร์ดไมโครคอนโทรลเลอร์ที่เชื่อมต่อกับเซนเซอร์วัดความชื้นในดิน วัตถุประสงค์เพื่อตรวจจับระดับความชื้นและสั่งการให้ปั๊มน้ำทำงานโดยอัตโนมัติเมื่อดินแห้ง ช่วยลดการใช้น้ำเกินความจำเป็นและอำนวยความสะดวกในการดูแลพืช
