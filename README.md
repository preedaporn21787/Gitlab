## ระบบรดน้ำต้นไม้อัตโนมัติ

ระบบรดน้ำต้นไม้อัตโนมัติด้วยบอร์ดไมโครคอนโทรลเลอร์ที่เชื่อมต่อกับเซนเซอร์วัดความชื้นในดิน วัตถุประสงค์เพื่อตรวจจับระดับความชื้นและสั่งการให้ปั๊มน้ำทำงานโดยอัตโนมัติเมื่อดินแห้ง ช่วยลดการใช้น้ำเกินความจำเป็นและอำนวยความสะดวกในการดูแลพืช

## แล็บ BJT Common-Emitter DC Bias (ENG29 2121)

แอป Flask สำหรับคำนวณจุดทำงานกระแสตรง (Q-point) ของทรานซิสเตอร์ BJT ชนิด NPN
ในวงจรไบแอสแบบแบ่งแรงดัน คอนฟิกูเรชันคอมมอน-อีมิเตอร์

**อินพุต 7 ค่า:** VCC, R1, R2, RC, RE, β, VBE

**เอาต์พุต:** I_B, I_C, I_E (mA) และ V_B, V_C, V_E, V_CE (V) พร้อมการจำแนกเขต
การทำงาน (คัตออฟ / แอคทีฟ / อิ่มตัว) และการตรวจสอบความถูกต้องของข้อมูลนำเข้า

ผลลัพธ์ถูกตรวจสอบไขว้กับวิธีวิเคราะห์โหนด (nodal analysis) ซึ่งคิดแยกจากวิธีหลัก
(วงจรสมมูลเทเวนิน) อย่างเป็นอิสระ

### วิธีใช้งาน

วิธีที่สั้นที่สุด (สคริปต์จะสร้าง `.venv` และติดตั้ง dependencies ให้เองถ้ายังไม่มี):

```powershell
.\run.ps1
```

หรือทำเองทีละขั้น:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python app.py
```

> ต้องใช้ `.\.venv\Scripts\python` เท่านั้น ถ้าพิมพ์ `python app.py` เฉย ๆ จะได้
> `ModuleNotFoundError: No module named 'flask'` เพราะ Flask ติดตั้งไว้ใน venv

เปิด `http://127.0.0.1:5000`

### การรันเทสต์

```powershell
.\.venv\Scripts\python -m pytest -q
```
